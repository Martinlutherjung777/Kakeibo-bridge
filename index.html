  3. Under Redirect URI, pick platform Single-page application (SPA) and paste the address shown below.
  4. After creation, go to API permissions → Add a permission → Microsoft Graph → Delegated → add Files.ReadWrite.AppFolder.
  5. Copy the Application (client) ID from the Overview page and paste it below.
